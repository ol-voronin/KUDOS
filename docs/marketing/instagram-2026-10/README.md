## Перемалювати пости

```bash
pip install pillow
# Шрифти (SIL OFL) з Google Fonts покласти в fonts/:
#   Unbounded-800.ttf, Onest-700.ttf, Onest-500.ttf
python3 render.py   # пише posts/01.png … 10.png
```

Стиль узято з сайту: Unbounded ExtraBold для заголовків, Onest для тексту; кольори ink `#0B0B0B`, paper `#F6F6F3`, red `#DF2A35`, yellow `#FDCA41`, teal `#0E6B60`, blue `#3A5A85`.

## Figma

Макети мали лягти у файл «Бабака: пост-знайомство» в Figma, але Figma-конектор зараз авторизований робочим акаунтом без доступу до цього файлу, а створювати файли в робочому просторі роботодавця не можна. Щойно Figma підключать акаунтом-власником файлу — пости переносяться туди з цих самих текстів і зображень.
