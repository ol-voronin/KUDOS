# Налаштування сайту, меню й головна на блоках

    pnpm install
    pnpm --filter @dt/contracts build
    ./scripts/setup-neon.sh
    pnpm -r typecheck && pnpm -r test
    git add -A && git commit -m "Налаштування сайту й меню в базі, головна на блоках" && git push

Міграція `20260826110000_site_settings` створює дві таблиці й **одразу
вписує наявні значення** — контакти, реквізити та обидва меню. Після накатки
сайт має виглядати точно так само, як до неї.

## Що змінилося по суті

**Реквізити переїхали з коду в базу.** Був `config/site.ts`; тепер —
`/admin/nalashtuvannya`. Той самий запис живить футер, метадані сторінок і
всі підстановки `{{brand}}`, `{{phone}}`, `{{cityIn}}` у текстах.

**Підстановку робить API, а не браузер.** Раніше таблиця значень лежала у
вебі — тобто була другою копією реквізитів поруч із базою. Тепер сторінка
приїжджає вже з реальним телефоном, а у вебі немає ані таблиці токенів, ані
самих контактів. Редактор бачить `{{phone}}`, перегляд і сайт — номер.

**Меню редагується.** Шапка й колонки футера — рядки в базі. Вимкнений пункт
зникає з сайту, але лишається в адмінці: пункт, прибраний на місяць, не треба
набирати заново.

**Головна — сторінка з CMS.** Slug `home`, показується за `/`. Той самий
редактор, попередній перегляд і історія версій, що й у решти. `/home` віддає
301 на `/`, у карті сайту її немає окремим рядком.

## Дрібниці, які варто знати

  · **Зміна налаштувань скидає кеш усього сайту** (`revalidate` зі шляхом
    `*`). Перелічити «які сторінки залежать від телефону» неможливо, а
    спроба закінчується сторінкою, яку забули.
  · **`{{telegramUrl}}` можна ставити в `href` блока.** Перевірок три:
    налаштування не приймають адресу без `https://`, у блоці дозволена лише
    підстановка цілком, а на рендері адреса перевіряється ще раз — уже
    підставленим значенням.
  · **У заголовку героя `**отак**` малюється акцентним кольором.** Це єдине
    оформлення, доступне редактору в H1, і його достатньо.
  · **`config/site.ts` лишився запасним варіантом** на випадок, коли API
    мовчить. Краще показати вчорашні контакти, ніж порожній футер.

## Що зникло з головної

Намальована SVG-морда в герої (була заглушкою на місці фото) і порожні стани
«каталог наповнюється». Порожній блок тепер просто не малюється, а текст про
наповнення можна написати блоком — і змінити без деплою.
