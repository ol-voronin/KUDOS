# Матеріали: блог, привʼязаний до каталогу

    pnpm install
    pnpm --filter @dt/contracts build
    ./scripts/setup-neon.sh
    pnpm -r typecheck && pnpm -r test
    git add -A && git commit -m "Матеріали: /statti, привʼязка до порід і колекцій, розмітка Article" && git push

Міграція `20260826090000_articles` додає дві таблиці звʼязків. Сідер створює
перший матеріал — «Як прати одяг із принтом».

## Що зроблено

Стаття — це **та сама сторінка з блоків**, тільки `kind = ARTICLE`. Редактор,
попередній перегляд, історія версій, чернетки — спільні. Окрема сутність
означала б другий редактор і другу історію версій заради різниці в адресі.

Відрізняється оболонка й адреса:

  · `/statti` — стрічка;
  · `/statti/<адреса>` — матеріал: дата, час читання, обкладинка, звʼязки;
  · `/<адреса>` для матеріалу віддає 301 на `/statti/...` — щоб той самий
    текст не жив за двома адресами;
  · розмітка `Article` і `BreadcrumbList`;
  · у карті сайту матеріал стоїть під `/statti`, а не за адресою, з якої
    йде редірект.

## Головне, заради чого це

Привʼязка до порід і колекцій. Матеріал про коргі стоїть на сторінці коргі —
там, куди люди приходять із пошуку, а не в стрічці за датою, де через місяць
його ніхто не знайде.

Ставиться в редакторі: розділ «Про що матеріал», кнопки порід і колекцій,
зберігається одразу.

## Час читання

Рахується з блоків, а не зберігається полем: поле редактор або не заповнить,
або заповнить один раз — і воно розійдеться з текстом на першій правці.

## Новий блок

«Останні статті» — блок **ядра**, не магазину: нічого не знає про каталог,
тому в ньому немає фільтра за породою. Матеріали про породу показує сама
породна сторінка, де цей звʼязок і живе.

## Чого свідомо немає

  · **пошуку по статтях** — `/search` шукає принти; додати туди матеріали
    варто тоді, коли їх стане більше десятка;
  · **тегів** — породи й колекції вже є таксономією, друга поверх них
    роздвоїла б навігацію;
  · **автора** — підписувати матеріали іменем, якого немає на сайті, гірше,
    ніж не підписувати. У розмітці автор — організація.
